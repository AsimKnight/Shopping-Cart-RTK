🛒 React Shopping Cart

A responsive shopping cart application built with React.js, Redux Toolkit, Tailwind CSS, and React Router.

This project was built to put my React concepts into practice and understand how different technologies work together in a real-world frontend application.

- ➕ Increase product quantity

💡 What I Learned

🔄 Redux Toolkit in a Real Application

I learned how Redux Toolkit can simplify global state management and how it can be used when multiple components need access to shared application state.

🛒 Building a Real-World Cart

I implemented complete cart functionality, including:

- Adding products
- Managing quantities
- Removing products
- Maintaining cart state across the application

This helped me understand how state flows between different components in a real application.

🧩 Immer.js & "produce()"

One of the most interesting concepts I learned was how Immer.js makes immutable state updates easier to write.

It also helped me understand why Redux Toolkit allows code that looks like we're directly mutating state while still maintaining immutable updates internally.

🧭 React Router

I used React Router to create navigation between different sections of the application and make the experience feel more like a real e-commerce website.

📱 Responsive Design

I used Tailwind CSS to create a responsive interface that works across different screen sizes, including desktop, tablet, and mobile devices.

🚀 GitHub & Deployment

I practiced using Git and GitHub to manage and publish the project, and deployed the application using Vercel.
